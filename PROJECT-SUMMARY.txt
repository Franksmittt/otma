OTMA PROJECT SUMMARY (current state)
====================================

Purpose
-------
This document is a high-level snapshot of the OTMA (On The Move Australia) Next.js site: what it does, how it is structured, and what has been implemented recently. It is meant for humans and AI assistants joining the project.

Tech stack
----------
- Next.js 15 (App Router), React 19, TypeScript
- Tailwind CSS v4 (CSS-first config in `src/app/globals.css` with `@theme`)
- `next/font` for Inter (body) and Montserrat (headings)
- `next/image` for optimized images (hero, gallery, blog, partners, etc.)

Repository layout (main areas)
------------------------------
- `src/app/` — App Router pages and layouts (`layout.tsx`, `page.tsx`, route segments)
- `src/components/` — UI components (bands, cards, header/footer, gallery, quote flow, etc.)
- `src/lib/` — Shared config and utilities (`site-config.ts`, `gallery-images.ts`, `blog-posts.ts`, `quote-storage.ts`, etc.)
- `public/` — Static assets (`images/`, `logos/`, `videos/`, `documents/`, `favicon.ico`, etc.)
- `scripts/` — One-off tooling (e.g. `gallery-order.txt` for gallery import order)

Site configuration
------------------
- **Branding & contact:** `src/lib/site-config.ts` — company name, phone, email, address, suburbs list, social links, partner logos, service links, blog metadata, etc.
- **Header navigation:** `HEADER_NAV` — Home, About Us, Services, Gallery, Contact Us (flat links; no mega-menu).
- **Footer navigation:** `NAV_LINKS` — includes Gallery plus core pages and legal links.
- **Services hub:** `SERVICE_LINKS` drives the Services index cards and related cross-links.

Key routes (user-facing)
------------------------
- `/` — Homepage: client hero carousel (`HomeHeroCarousel`), trust strip, how-it-works, monitoring band, full-service cards, long-distance / insurance / about bands, suburbs, blog preview, FAQ `PageBand`, partners, contact strip, final CTA (`src/app/page.tsx`).
- `/about` — About: `ServiceMasthead` (stacked intro for long copy), lede quartet, pillars, leadership, service grid, PMA/AMOSA cards, map (`src/app/about/page.tsx`).
- `/services` — Services hub with cards from `SERVICE_LINKS`.
- `/services/*` — Individual service pages (local, interstate, office, piano, packing, storage, etc.) using shared patterns (`ServiceMasthead`, `ServiceCtaBand`, `PageBand`, etc.).
- `/gallery` — Full gallery: responsive grid + lightbox (`GalleryGrid`), images from `src/lib/gallery-images.ts` (116 files under `public/images/gallery/` as `otma-gallery-001.jpg` … `otma-gallery-116.jpg`). Import order is documented in `scripts/gallery-order.txt`.
- `/blog` and `/blog/[slug]` — Blog index and posts driven by `src/lib/blog-posts.ts`.
- `/quote` — Multi-step quote flow; steps forward `searchParams` so data persists across navigation (`src/app/quote/*`, `QuoteLayoutClient`, step components).
- `/contact`, `/faq`, `/reviews`, `/privacy`, `/terms`, `/cookies` — Supporting pages.
- `/login` — Internal “Pro Ad Studio” demo/tools area (separate from public marketing IA); not linked from main header/footer.

Global chrome
-------------
- **Header:** `SiteHeader` — logo, `HEADER_NAV`, phone CTA, mobile drawer with accordion sections built from `SERVICE_LINKS` / quote CTA.
- **Footer:** `Footer` — `NAV_LINKS`, contact block, socials, legal strip.
- **Sticky CTA:** `StickyCta` — mobile-first floating “Get a free quote” button (`lg:hidden`).

Design system (recurring primitives)
------------------------------------
- **`PageBand`** — Section wrapper: optional `eyebrow`, `title`, `description`, `actions`, `variant` (`default` | `tint` | `dark`), `align`, `maxWidthClass`, `bleed`.
- **`ServiceMasthead`** — Page hero for inner pages; `layout` `split` | `stacked` (stacked used where intro copy is long, e.g. About).
- **`ServiceCtaBand`** — Mid-page CTA band (quote + phone); description slot uses a wrapper `div` for rich content / links without invalid nested `<p>` tags.
- **Cards / grids:** `ServiceCard`, suburb lists, partner grids, etc., aligned with Tailwind tokens from `@theme`.

Gallery implementation
------------------------
- **Data:** `GALLERY_IMAGE_COUNT` and filenames in `src/lib/gallery-images.ts`.
- **Assets:** `public/images/gallery/otma-gallery-*.jpg` only (root-level Facebook export filenames are not used; `/*_n.jpg` is gitignored to avoid accidental re-adds).
- **UI:** `src/components/gallery/GalleryGrid.tsx` — grid, lightbox, keyboard navigation, reduced-motion friendly transitions.
- **SEO:** `/gallery` included in `src/app/sitemap.ts`; gallery uses `next/image` with descriptive `alt` text.

Quote flow
----------
- Steps under `src/app/quote/` with a shared `QuoteLayoutClient` and per-step forms.
- **Persistence:** `sessionStorage` via `src/lib/quote-storage.ts` for in-session drafts; URL `searchParams` used to pass state between steps.
- **Analytics hook:** `src/lib/quote-analytics.ts` — placeholder for future GTM/events.

SEO & metadata
---------------
- Root `layout.tsx`: `metadataBase`, default title template, Open Graph / Twitter, `robots` helpers, `verification` placeholder.
- `src/app/robots.ts` and `src/app/sitemap.ts` — crawl rules and URL list (includes `/gallery`).
- Page-level `metadata` / `generateMetadata` where needed (blog posts, etc.).
- Structured data: `src/components/JsonLd.tsx` — `LocalBusiness` / `MovingCompany` style JSON-LD on the homepage.

Content & tone
---------------
- Australian English; plain-language, trust-first copy.
- User rule: avoid em dashes in user-facing strings (prefer commas, colons, or “ - ”).

Accessibility & UX notes
-------------------------
- Skip link, focus styles, semantic landmarks in layout.
- Reduced motion: `usePrefersReducedMotion` in gallery lightbox transitions.
- Responsive layout: broad use of `min-w-0`, grid column fixes, and `break-words` / `overflow-wrap` on long headings and rich text bands to avoid horizontal overflow on small viewports.

Recent structural themes (historical)
--------------------------------------
- Replaced early “gallery strip on homepage” with the current marketing homepage sections and a dedicated `/gallery` route.
- About page rebuilt around `ServiceMasthead` (stacked), pillars, leadership, and accreditation cards.
- Gallery expanded to 116 images with ordered import and sitemap coverage.
- Quote flow wired with `searchParams` between steps and storage helpers.
- **Responsive pass:** `PageBand`, `ServiceMasthead`, `ServiceCtaBand`, and multiple pages/components updated for small-screen overflow and typography wrapping.

How to run locally
------------------
- `npm install`
- `npm run dev` — development server (Turbopack).
- `npm run build` / `npm start` — production build and serve.

Deployment notes
----------------
- `next.config.ts` sets `images.localPatterns` for local `public/` images and remote patterns for partner/hero URLs.
- Environment variables: `.env.example`-doc pattern; `.env*` gitignored.

End of summary
